关于

这个站点是什么

一个纯静态、零依赖、零构建的个人生活平台。所有内容都在仓库里的纯文本文件中， 推送即发布，断网可用，没有服务器、没有账号、没有跟踪脚本。

数据来源
  • 生活记录：./data/entries.json（schema v1）
  • 理财复盘：./data/finance.json（schema v1，v1.1 新增）
  • 前端一律只读，不提供任何新增 / 编辑 / 删除入口
怎么新增内容

手工编辑上面的 JSON 文件 → 保存 → 刷新页面验证 → 提交推送到 GitHub， Pages 会在数分钟内更新。字段与语法说明见 README 与 docs/data-schema.md。
